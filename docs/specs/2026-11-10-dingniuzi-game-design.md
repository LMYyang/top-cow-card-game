## 1. 项目概述

顶牛子（也叫顶牛、牛牌、拱牛、骨牌接龙）是华北流行的传统骨牌游戏（源自推牌九，32 张牌去掉 8 张杂牌留 24 张）。本项目用**一套代码**将其实现在以下全部平台：

| 平台 | 发布方式 |
|------|----------|
| 网页端 (H5) | uni-app H5 编译 |
| 安卓端 | HBuilderX 云打包 / 离线打包 |
| 苹果端 (iOS) | HBuilderX 云打包 |
| 微信小程序 | uni-app 微信小程序编译（普通小程序，非小游戏） |
| PC 端 | H5 响应式（牌桌容器居中，手机比例） |

**模式**：第一版为单机版（1 名真人玩家 + 3 个 AI 对手），架构上游戏逻辑与渲染完全分离，为二期联网多人对战预留能力。

## 2. 游戏规则（第一版）

### 2.1 牌组（24 张 · 13 种牌型 · 共 177 点）

每张牌有**两端点数**；两端相同的叫**横牌**，两端不同的叫**竖牌**。牌的总点数 = 两端点数之和。

| 名称 | 又名 | 点数 | 张数 | 牌型 | 两端点数 |
|------|------|------|------|------|----------|
| 大天 | 长六、天牌 | 12 | 2 | 横牌 | 六、六 |
| 虎头 | 斧头 | 11 | 2 | 竖牌 | 五、六 |
| 大五 | 长五、梅花 | 10 | 2 | 横牌 | 五、五 |
| 红十 | 金屏、红头、四六 | 10 | 2 | 竖牌 | 四、六 |
| 红八 | 大红、人牌 | 8 | 2 | 横牌 | 四、四 |
| 长三 | 大三、长衫 | 6 | 2 | 竖牌 | 三、三 |
| 一六 | 幺六、高脚七 | 7 | 2 | 竖牌 | 一、六 |
| 一五 | 幺五、铜棰 | 6 | 2 | 竖牌 | 一、五 |
| 一三 | 幺三、和牌、幺鹅 | 4 | 2 | 竖牌 | 一、三 |
| 二板 | 长二、板凳 | 4 | 2 | 横牌 | 二、二 |
| 地幺 | 长一、地牌 | 2 | 2 | 横牌 | 一、一 |
| 三六 | 杂九、黑九、歪脖九 | 9 | 1 | 竖牌 | 三、六 |
| 二六 | 杂八、平八 | 8 | 1 | 竖牌 | 二、六 |

- 去掉的 8 张杂牌（标准牌九 32 张中）：12、14、23、24、25、34、35、45
- 按端点数分类：一牌 8 张（地幺/一三/一五/一六）、二牌 3 张（二六/二板）、三牌 5 张（长三/三六/一三）、四牌（红牌）4 张（红八/红十）、五牌 6 张（大五/虎头/一五）、六牌 10 张（大天/虎头/红十/一六/二六/三六）
- 牌面为传统风格：白/象牙底、黑点或红点（红点牌张在 UI 阶段与用户确认）

### 2.2 开局流程

1. **洗牌分牌**：系统洗牌后平均分为四组，每组 6 张
2. **打骰定头牌**：由上一局赢家（第一局系统随机指定一人）掷**一颗骰子**定头牌：
   - 1 / 5 点 → 自己（掷骰者）
   - 2 / 6 点 → 下家
   - 3 点 → 对家
   - 4 点 → 上家
3. **起牌**：被骰子指到的人为头牌；*（传统规则中大庄还可指定一组牌给头牌，第一版省略指定环节，头牌的牌组由系统随机分配）*，头牌取一组，其余三家按逆时针依次取组，每人 6 张

### 2.3 出牌规则

1. **头牌先出**：头牌出第一张牌（受头牌限制约束，见 2.4）
2. **跟牌**：逆时针轮转，必须出与**桌面最新一张牌任一端点数相同**的牌
   - 例：头牌出大五（五、五），下家只能出其中一端是五的牌
3. **扣牌**：手中没有能接的牌时，必须选一张手牌扣下（背面朝上放自己扣牌区，本局不可再用）
4. **不能扣活牌**：手里有可以接的牌时，禁止扣牌
5. **结束**：每人的 6 张全部出完（净手）或扣完，一局结束
6. **桌面最新牌**：待接点数始终以桌面最新出的一张牌为准（被接的旧牌不影响）

### 2.4 头牌出牌限制（正式规则）

头牌第一张牌不能"拉"三家——即不能上一张其他三家都没有竖牌可接的牌：

1. 例：头牌手中有两张一三、一张三六、一张或两张长三，想出三牌，第一张不能上长三（长三只有自己有，其他人无三头竖牌可接）
2. 头牌有两张红十、一或两张红八，想出红牌必须先出红十
3. 头牌有二六、一或两张二板，想出二牌第一张必须出二六
4. 头牌有两张红八想第一张出红八，须两张同时打出（防止拦红帐者误判）

> **实现口径**：第 1 条为核心约束（首张牌必须在其余三家任一家手牌存在可接端点时才允许出）；第 2、3 条是"多张同类牌先出哪张"的引导规则，随第 1 条自然满足；第 4 条在单机版中表现为允许一次出两张红八（双张出牌动作）。

### 2.5 胜负条件

按各家**扣牌点数之和**计算：

- 扣牌点数**最少**的为**赢家**
- 点数最多的为**大庄**，其次**二庄**，再次**小庄**
- 几人点数相同时：赢时头牌或离头牌近者赢；输时头牌或离头牌近者庄大
- **四家净手**（都出完、无人扣牌）时：头牌赢，其余按出牌次序依次为大庄、二庄、小庄

### 2.6 记分规则（简化版）

- 赢家 +6 分
- 大庄 -3 分、二庄 -2 分、小庄 -1 分
- *传统规则中的"算帐翻番"第一版不实现（见 2.8）*

### 2.7 头牌连庄说明

- 第一局：系统随机指定一名玩家掷骰，按打骰结果定头牌
- 之后每局：**上一局赢家掷骰**，按 2.2 的骰点映射（1/5 自己、2/6 下家、3 对家、4 上家）定头牌

### 2.8 二期预留（本期不做）

- 联网多人对战（房间、匹配、断线重连）
- **算帐**（红帐、二三帐、五帐、一帐、砸红帐、闷五帐六种；成功则其余三家按大庄/二庄/小庄加倍付 6/4/2 分）
- **包庄**（算帐失败者代替其余两家输分，付给点数最小者 12 分；含"死砸""死拦红帐"判定）
- 大庄指定牌组给头牌的完整传统流程
- 其他俗语玩法（二三六对屁股、幺鹅亲嘴、大五并骨等）

## 3. 技术架构

### 3.1 技术栈

- **uni-app + Vue 3**（Composition API），JavaScript + JSDoc 类型注释
- 纯 CSS 绘制牌面（零图片资源，全平台一致、包体小）
- CSS transition/animation 实现动画（出牌飞行、扣牌翻转、骰子摇动）
- 自研轻量游戏状态机，平台无关

### 3.2 目录结构

```
top-cow-card-game/
├── src/
│   ├── core/                  # 纯游戏逻辑（平台无关，可单元测试，二期可复用于服务端）
│   │   ├── tiles.js           # 牌定义：24 张牌数据（名称、两端点数、横竖、颜色）
│   │   ├── deck.js            # 洗牌、分四组、发牌（支持注入随机种子）
│   │   ├── rules.js           # 跟牌判定、扣牌限制（不能扣活牌）、头牌限制、结算、庄位排名
│   │   ├── ai.js              # 中等 AI：出牌策略 + 记牌器
│   │   └── game.js            # 状态机：DEALING → PLAYING → SETTLE

│   │   └── result/            # 结算页
│   ├── components/
```

### 3.3 状态机

| 状态 | 说明 |
|------|------|
| DEALING | 洗牌、分四组、起牌动画 |
| PLAYING | 出牌/扣牌回合轮转 |
| SETTLE | 结算展示 |

- 状态机不依赖任何 DOM / uni API，纯函数驱动
- 只接受合法动作，非法动作被忽略并反馈（震动提示），从根源避免非法状态

### 3.4 AI 设计（中等强度）

- 维护记牌器（已出的牌 + 各家扣牌数），推测对手手牌
- 可接牌时优先出高牌（减少被扣的高点数损失）
- 扣牌时扣手里剩余总点贡献最小的牌
- 头牌首出时遵守"不能拉三家"限制，并倾向出有利于后续接龙的端点

### 3.5 数据持久化

- `uni.setStorage`（各端自动映射本地存储）：战绩记录、累计积分、设置项（音效开关）
- 单机版不做断线重连：切后台/杀进程后回到主菜单重新开局

## 4. 界面与交互

### 4.1 布局（竖屏）

```
┌─────────────────┐
│    [对家 AI]     │  ← 上：牌背、牌数、庄家/头牌标记
│ [左家] 中央 [右家] │  ← 左右：AI 状态区
│    出牌/扣牌区    │  ← 中央：桌面最新牌 + "待接: N" 提示 + 各家扣牌堆
│   [我的手牌]     │  ← 下：手牌 + 出牌/扣牌按钮
└─────────────────┘
```

### 4.2 核心交互

| 场景 | 交互 |
|------|------|
| 轮到我出牌 | 手牌上浮，可接的牌高亮金边，不可接置灰；点牌选中 → 点"出牌"确认（防误触） |
| 轮到我扣牌 | 提示"无牌可接，请扣牌"；点选一张 → 点"扣牌"，牌翻面飞入扣牌区 |
| 我为头牌首出 | 可出的牌均高亮（不满足"不拉三家"的牌自动排除并置灰，附提示） |
| AI 行动 | 区域气泡提示（"接 5 点"/"扣牌"），牌从 AI 区域飞到中央；思考延时 600-1000ms |
| 接牌提示 | 中央常显当前待接端点数（如"待接：五"） |
| 结算 | 四家扣牌翻开 → 点数排序 → 冠军高亮 → 庄位（大庄/二庄/小庄）标注 → 积分滚动变化 |
| 音效 | 出牌、扣牌、胜利音效，设置中可关闭 |

### 4.3 页面流程

主菜单（开始游戏 / 战绩 / 设置）→ 牌桌 → 结算页（点数对比、庄位、积分变化、再来一局）
