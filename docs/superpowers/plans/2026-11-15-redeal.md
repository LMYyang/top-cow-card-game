# 申请重新发牌（redeal）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现顶牛子「申请重新发牌」规则——手牌满足两红八无红十、或六张全横牌时，可在头牌首出前申请重发，由申请人打骰重新定头牌摸牌；单机与联网双模式同时生效。

**Architecture:** core 状态机新增纯函数 `canRedeal`/`redeal`（窗口校验 + 重置牌局 + 掷骰权移交 + `redealUsed` 防循环）；单机由 useGame 接入（含 AI 自动申请与重发后自动掷骰）；联网由 rooms.js 新增 `game.redeal` 动作 + AI 托管代申请，客户端 useNetGame 订阅 `game.redealt` 推送；game.vue 加按钮与重发复位 watch。

**Tech Stack:** Vitest（现有测试栈）、Vue 3 Composition API、Node 22 ESM（服务端直接复用 src/core）。

**Spec:** `docs/superpowers/specs/2026-11-15-redeal-design.md`

```js
/**
 * 是否满足「申请重新发牌」牌型（发牌后、首出前）：
 * 1. 两红八（4|4）且无红十（4|6）；
 * 2. 六张全是横牌（两端点数相同）。
 */
export function canRedeal(hand) {
  if (!Array.isArray(hand) || hand.length !== 6) return false
  const redEights = hand.filter((t) => t.a === 4 && t.b === 4)
  const hasRedTen = hand.some((t) => t.a === 4 && t.b === 6)
  if (redEights.length === 2 && !hasRedTen) return true
  return hand.every((t) => t.a === t.b)
}
```

注意：红牌判定按端点数值（`4|4`、`4|6`）而非 `red` 字段，与 `game.js` 中 `isRedEightPair` 的既有口径一致（`src/core/game.js:28`）。

```js
/**
 * 申请重新发牌：手牌满足 canRedeal 且尚无人出牌时，重置牌局并由申请人掷骰。
 * 每人每局限 1 次（redealUsed 按座位记录，重发后其余座位仍可各申请一次）。
 */
export function redeal(g, seat) {
  if (g.state !== 'PLAYING') return { ok: false, reason: '当前不可申请重新发牌' }
  if (g.tableHistory.length > 0) return { ok: false, reason: '已开始出牌，不能再申请重新发牌' }
  if (g.redealUsed.has(seat)) return { ok: false, reason: '本局已申请过重新发牌' }
  if (!canRedeal(g.players[seat].hand)) return { ok: false, reason: '手牌不满足重新发牌条件' }
  g.players.forEach((p) => { p.hand = []; p.kept = [] })
  g.tableTile = null
  g.openEnds = null
  g.tableHistory = []
  g.leaderSeat = null
  g.currentSeat = null
  g.rollerSeat = seat // 申请人打骰
  g.redealUsed.add(seat)
  g.state = 'ROLLING'
  return { ok: true }
}
```

(a) 动作代理区（`myDiscard` 之后，约第 223 行）新增：

```js
/** 申请重新发牌（双模式代理）：成功后状态回 ROLLING；失败 toast（net）或静默（solo 由 core reason 决定） */
const redealBusy = ref(false)
async function onRedeal() {
  if (redealBusy.value) return
  redealBusy.value = true
  try {
    const res = await gameApi.value?.redeal()
    if (res && !res.ok) uni.showToast({ title: res.reason || '申请失败', icon: 'none' })
  } finally {
    redealBusy.value = false
  }
}
```

(c) **重发复位 watch**：既有 `rollerSeat` watch 在「新 roller === 旧 roller」时不触发（如原掷骰者自己申请重发），需按 state 复位。在既有 `watch(() => view.value.rollerSeat, ...)` 之后新增：

```js
// 重发复位：redeal 使状态 PLAYING→ROLLING，若掷骰权恰好回到原掷骰者，rollerSeat watch 不触发，
// 上一局的揭示文案/回弹/终局节奏残留会顶掉掷骰按钮（卡死）。按 state 翻转统一复位。
watch(
  () => view.value.state,
  (state, old) => {
    if (state === 'ROLLING' && old === 'PLAYING') {
      clearTimers()
      diceLanded.value = false
      leaderRevealed.value = false
      randomFace.value = 1 + Math.floor(Math.random() * 6)
      settleBrief.value = false
      fx.value.revealKept = false
      fx.value.settleShow = false
      fx.value.lastMove = null
      latestHidden.value = false
    }
  }
)
```
